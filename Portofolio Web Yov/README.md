# Yova Rezky Apriliano — Network Administrator Portfolio

Portofolio statis berbasis HTML, CSS, dan JavaScript. Konten pendidikan, pengalaman, keterampilan, sertifikasi, dan proyek dirangkum dari CV.
Situs tersedia dalam Bahasa Indonesia dan English melalui pemilih bahasa di navigasi. Profil pendidikan menggunakan gelar Teknik Informatika.

## Menjalankan
1. Buka folder ini di Visual Studio Code.
2. Jalankan `index.html` dengan Live Server atau buka langsung di browser.

## Aset
- Foto profil menggunakan `image/Pas Foto.png`.
- Logo pendidikan yang digunakan: logo [UMJ](image/education/umj.png) dari [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Lambang_Resmi_UMJ.png) dan logo [SMKIT Ihsanul Fikri](image/education/smkit-ihsanul-fikri.png) dari [situs resmi sekolah](https://www.smkitihsanulfikri.sch.id/).
- Logo HMIF dan Celerates ditampilkan pada bagian pengalaman; logo Celerates bersumber dari [situs resminya](https://www.celerates.co.id/).
- Bukti sertifikat yang tersedia, termasuk sertifikat kompetensi BNSP dan kelulusan Celerates, disimpan lokal di `image/certificates/` dan dapat dibuka dari bagian sertifikasi.
- Ikon teknologi dan tools disimpan lokal di `image/skills/`; sumbernya [Devicon](https://github.com/devicons/devicon) dan [Simple Icons](https://simpleicons.org/).
- Tombol Download CV menggunakan `cv-yova.pdf`.
- Proyek presensi RFID menggunakan foto perangkat dan dashboard rekap presensi yang tersedia, serta tautan ke source code GitHub.
- Proyek Moodify ditautkan ke repositori GitHub dan dideskripsikan sebagai aplikasi rekomendasi lagu Spotify berdasarkan suasana hati.
- Periode MTCNA pada CV tercatat 2018–2023; portofolio menampilkan periode tersebut tanpa menyebut sertifikasi aktif.

## Tema
Gunakan tombol **Gelap** dan **Terang** di navigasi untuk memilih tema. Pilihan tema disimpan di browser.

## Intro koneksi jaringan
Animasi kabel RJ45 tersambung ke switch secara otomatis dan membuka portofolio dalam sekitar 3 detik.
